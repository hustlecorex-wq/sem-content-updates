# Sem Content System — downloads

This repository holds the finished app and nothing else. No source code lives here.

**[Download the latest version](../../releases/latest)**

## Which file do I want

| Your machine | The file |
|---|---|
| Mac, 2020 or newer (Apple M1, M2, M3, M4) | the one ending **`_aarch64.dmg`** |
| Mac, older, with an Intel processor | the one ending **`_x64.dmg`** |
| Windows | the one ending **`_x64-setup.exe`** |

Not sure which Mac you have? Apple menu → **About This Mac**. If the first line says
**Chip**, take the `aarch64` one. If it says **Processor**, take the `x64` one.

## Installing it on a Mac

Open the `.dmg` and drag the app into Applications. That is the whole of it — the app is
signed and notarized by Apple, so it opens straight away with no warning and no trip into
System Settings.

There is nothing to open afterwards and nothing to press. It sits in the menu bar and makes
the videos you asked for.

## Updating

Nothing to do. The app checks for a new version by itself and installs it when it finds one,
and it will not do that in the middle of making a video.

## What the app needs

- macOS 11 or newer
- Claude Code, signed in, for the writing and the edit decisions
- The media folder in Google Drive that the dashboard points at
